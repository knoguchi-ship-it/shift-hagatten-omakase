# シフトはがってんおまかせ！ 製品仕様（改訂版）

## 1. 目的と対象

介護施設のシフト管理者が、ローカルPCだけで、職種・勤務種別・希望休・人員配置条件を満たす月次勤務表を作成、確認、Excel出力できるWindowsデスクトップアプリケーション。

対象環境は Windows 11（RAM 4GB／2コアCPU）とし、ネットワーク接続を前提にしない。

## 2. 画面と利用フロー

1. **ダッシュボード** — 対象月を作成または既存月を開く。
2. **マスタ** — 職種、職員、勤務種別、制約を管理する。
3. **条件設定** — 希望休と、日付・勤務種別・職種ごとの必要人数を入力する。
4. **シフト編集** — 自動生成、違反確認、セル編集、保存、Excel出力を行う。
5. **データ管理** — SQLiteバックアップ／復元を行う。

## 3. マスタ仕様

### 3.1 職種マスタ

- 職種名（例：介護職、看護職）、表示順、論理削除日時を保持する。
- 職種を削除する際は、紐づく職員・必要人数設定への影響を表示し、論理削除する。

### 3.2 職員マスタ

- 氏名、主職種、雇用区分、月間勤務日数下限・上限、勤務不可曜日、勤務不可種別、論理削除日時を保持する。
- 追加、編集、削除、復元を提供する。物理削除は行わない。

### 3.3 勤務種別マスタ

- 名称、表の略称、色、開始・終了時刻、勤務日として数えるか、論理削除日時を保持する。
- 夜勤入り→夜勤明け等の翌日制約を設定できる。

## 4. 配置・自動生成仕様

### 4.1 ハード制約

- 希望休、勤務不可曜日、勤務不可種別を割り当てない。
- 同日勤務NGペアを割り当てない。
- 勤務種別の翌日制約を守る。
- 日付 × 勤務種別 × 職種の必要人数を充足する。

### 4.2 ソフト制約

- 月間勤務日数上限・下限、連勤上限、勤務回数の偏りを可能な限り満たす。
- ハード制約を満たせない場合でも、未割当と理由を明示した案を出す。

### 4.3 実行・検証

- 自動生成はRendererと分離したWorkerで実行し、進捗と中止を提供する。
- 最大実行時間は180秒。時間切れ時は現時点の案と未充足一覧を返す。
- セル変更後、0.5秒以内に関連する違反を再検証する。

## 5. シフト編集グリッド

- 氏名・職種列、日付ヘッダーを固定し、仮想スクロールする。
- 矢印キーで移動、Enterで勤務種別選択、Escで編集取消、コピー／貼り付けを提供する。
- 未保存・保存済み・違反の状態を明示する。
- 違反一覧から該当セルへ移動できる。

## 6. Excel・データ保護

- 既存の勤務表に近い月タイトル、曜日・日付列、職員行、勤務色、勤務別集計、横向き印刷を出力する。
- SQLiteはアプリ内包し、バックアップと復元を提供する。復元前に自動バックアップを作る。
- エラー・クラッシュ調査用ログは30日間ローテーションする。

## 7. 受入基準

- 職種別必要人数を設定し、自動生成結果と違反一覧で確認できる。
- 全マスタで追加・編集・論理削除・復元ができる。
- 50名×31日の表で操作不能にならず、キーボードのみでも編集できる。
- 主要フロー（マスタ→条件→生成→編集→Excel→バックアップ）をE2Eテストで通す。
